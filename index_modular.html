Atlassian Setup Guide

  1. Cloud ID / Subdomain: Click Short Subdomain and type your site name (e.g. acme-corp if your URL is https://acme-corp.atlassian.net).
  2. Workspace ID: Click Short Schema ID and type your schema number (e.g. 3 or 14), OR click Long UUID and enter your 36-character Workspace UUID.
  3. Email & API Token: Enter your Atlassian account email and generated API Token (from id.atlassian.com).
  4. Click Save & Sync: Click Save Changes, then click Sync Now under the connection status card!
  5. Alternative CSV Import: If you have a spreadsheet or exported CSV file from Jira, open Audit Trail (clock icon) and click Import (.csv / .json) for 1-second instant loading!
