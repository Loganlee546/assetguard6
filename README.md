A premium, Atlassian-inspired Single Page Application (SPA) for real-time IT asset tracking, QR scanning, and Atlassian Cloud synchronization.

## 🚀 Live Demo
Once deployed, your link will look like: `https://your-username.github.io/asset-management-assistant/`

## ✨ Features
- **📦 Atlassian Sync**: Pull live assets directly from Atlassian Cloud (Jira Service Management) using AQL.
- **📸 QR Scanner**: Built-in camera support for instant asset lookup and check-in/out.
- **🌓 Dark Mode**: Intelligent theme switching that persists across sessions.
- **🌍 Bilingual**: Full support for English and Spanish (EN/ES).
- **🛡️ Secure**: API credentials are stored locally in your browser and never touch a server.
- **📊 Interactive Metrics**: Real-time dashboard for Total, Open, Owned, and Broken assets.

## 🛠️ Setup & Deployment

### 1. Local Development
Simply clone this repository and open `index.html` in any modern web browser.
```bash
git clone https://github.com/your-username/asset-management-assistant.git
cd asset-management-assistant
```

### 2. GitHub Pages Deployment
1. Upload these files to a new GitHub Repository.
2. Go to **Settings > Pages**.
3. Under **Branch**, select `main` and `/ (root)`.
4. Click **Save**. Your site will be live in minutes!
